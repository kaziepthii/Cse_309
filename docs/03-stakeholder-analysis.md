# Personal Finance Tracker - Stakeholder Analysis

## Stakeholder Categories

### Primary Stakeholders

| Stakeholder | Role | Key Expectation |
|-------------|------|-----------------|
| **End Users** | Daily platform users — track income, expenses, and savings | Simple interface, accurate tracking, instant balance updates, edit/delete transactions |
| **Developer** | Project builder and maintainer — implement full stack, manage code, and ensure quality | Clean code, proper documentation, functional features, on-time delivery |
| **Course Instructor** | Evaluator and reviewer — assess project quality and documentation | End-to-end working application, clean documentation, proper SDLC compliance |

---

### Secondary Stakeholders

| Stakeholder | Role | Key Expectation |
|-------------|------|-----------------|
| **Testers** | Quality assurance team | Bug-free application, proper error handling |
| **UI/UX Designer** | Interface designer (if applicable) | Clean, responsive, user-friendly design |

---

### Internal Stakeholders

| Stakeholder | Role |
|-------------|------|
| **Developer** | Full-stack implementation |
| **QA Tester** | Application testing |
| **Database Designer** | Database schema design |

---

### External Stakeholders

| Stakeholder | Role |
|-------------|------|
| **University Faculty** | Project evaluator |
| **React Community** | Open-source libraries and support |
| **FastAPI Community** | Backend framework support |
| **GitHub** | Code hosting and version control |
