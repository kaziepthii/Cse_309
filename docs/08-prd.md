# Product Requirements Document (PRD)

## Product Information
| Item | Detail |
|------|--------|
| Product Name | Personal Finance Tracker |
| Product Type | Web Application |
| Target Audience | Students, Young Professionals |
| Platform | Web (Browser) |

## Core Features

| Feature | Description | Priority |
|---------|-------------|----------|
| User Registration | Create new account with username/password | High |
| User Login | Login with credentials | High |
| Add Transaction | Add income or expense transaction | High |
| View Transactions | See all transactions in a list | High |
| Update Transaction | Edit transaction details | High |
| Delete Transaction | Remove transaction | High |
| View Summary | See total income, expense, balance | High |
| Search Transactions | Filter by description | Medium |

## Technical Requirements

| Component | Technology |
|-----------|------------|
| Frontend | React + TypeScript + Vite |
| Backend | FastAPI + Python |
| Database | SQLite |
| API | RESTful |
| Authentication | Session-based |

## Success Criteria
1. User can register and login ✅
2. User can add transactions ✅
3. User can view transactions ✅
4. User can edit transactions ✅
5. User can delete transactions ✅
6. User can see summary ✅
7. User can search transactions ✅
